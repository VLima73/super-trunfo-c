# Super Trunfo em C – Tema 3

Projeto desenvolvido para a disciplina de Engenharia de Software.

## Descrição
Implementação do jogo Super Trunfo em linguagem C, com foco no uso de
estruturas de decisão (`if`, `if-else`, `switch` e operador ternário).

O programa realiza:
- Comparação de cartas por um atributo
- Comparação por dois atributos com soma
- Regra especial para densidade demográfica (menor valor vence)

## Compilação
```bash
gcc super_trunfo.c -o super_trunfo
